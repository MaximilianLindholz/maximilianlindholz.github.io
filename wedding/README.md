# Max & Ev — Wedding Page

A static site (no build step) for GitHub Pages.

- `content.js` — **all the text**: venues, times, things to do, letters. Edit this.
- `style.css` — design & colours
- `script.js` — page logic (date → Itinerary / Things to Do / Letter)

## Preview locally

    python3 -m http.server 8000   # from the Website root, then open http://localhost:8000/wedding/

## Publish

Part of the main site — deployed with it at `https://maximilianlindholz.github.io/wedding/`.
